# StudyFloat UI 重设计说明

> 日期：2026-11-20
> 范围：启动器 / 设置 / 分P选择 / 扫码登录 四个窗口
> 截图：`demo_out/v6/`（launcher、settings_account、settings_playback、settings_window、parts、qr）

## 一、原来的问题

旧版不是「元素不够多」，而是**没有层级、没有取舍**：

1. **配色是通用 AI 深色皮肤**：蓝黑底 `#0c0f11` + 薄荷绿 `#3ddc97`，绿色同时出现在主按钮、开关、选中文字、滑杆、登录状态上。一个颜色干了五种活，结果哪种都不突出。
2. **所有标题都加粗**：页标题 23px bold、行标题 13px bold、分区标签 bold。字重只有「粗」和「更粗」，读者扫不出主次。
3. **卡片套卡片**：设置页用圆角卡片分区，卡片里再放控件；深色底上叠两层灰，页面发浑。
4. **控件右边缘不齐**：Cookie 控件 300px、滑杆 258px、分段 248px，三条不同宽度的右边界，纵向扫视时找不到「可改的地方」。
5. **启动器三个按钮同权重**：播放、扫码登录、设置都是 38px 高的按钮，主操作只比次操作宽一点，用户第一眼不知道先点哪。
6. **分P列表是一行拼接字符串**：`P3   第 3 讲…   [15:00]`，编号 / 标题 / 时长没有列，154P 的课程很难扫。

## 二、设计主张

**「暖夜里的阅读灯」**：暖黑底，黄铜只照亮当前要做的一件事。

- 底色从蓝黑换成暖黑（`#0C0B0A`），去掉冷感。
- 唯一强调色是黄铜 `#DCA85A`，只给四类东西：主按钮、当前项、滑杆已填充段、开关 ON。
- 字重只保留 400 / 600 两档；标题靠字号和留白建立层级，不靠「全部加粗」。
- 一个页面只有一条控件轨道：所有可操作控件的右边缘对齐。
- 窗口圆角 8（Win11 DWM 原生、抗锯齿）/ 面板 12 / 控件 10，旧系统用 mask 兜底圆角。

## 三、设计令牌

| 类别 | 值 |
|---|---|
| 底色 | `#0C0B0A`，顶部渐变到 `#171412` |
| 面板 / 输入 | `#141210`、`#1A1714` |
| 线 | `#2A2521`，悬停 `#3A332B` |
| 主文字 | `#F2EDE4`（暖白，不用纯白） |
| 次要 / 说明 | `#A89F92` / `#8D8375` |
| 强调 | `#DCA85A`，悬停 `#EBBB74`，按下 `#C6903F` |
| 危险 | `#E27C68`（珊瑚，不引入第二种绿） |
| 字号 | 22 页标题 / 15 品牌 / 13 行标题 / 12 正文 / 11 说明 / 10 微标签 |
| 字重 | 400 正文，600 标题；无 700 |
| 圆角 | 8 窗口（DWM 原生）/ 12 面板 / 10 控件 / 8 小按钮 |
| 间距 | 8 的倍数：8 / 12 / 16 / 20 / 24 / 30 |

字体：`Segoe UI Variable Text`（Win11）→ `Segoe UI`（Win10）→ `Microsoft YaHei UI`（中文）。数字与时间码用 `Consolas`，便于等宽扫读。

## 四、四个窗口的版式

### 启动器（460 × 313）

- 标题栏：22px 品牌标 + 两行品牌（StudyFloat / 桌面悬浮播放器）+ 最小化 / 关闭。
- 字段标签行：左「视频链接 / BV 号」，右「Enter 开始播放」。
- 输入框 46px，右侧内嵌「粘贴」；聚焦时只亮一条黄铜边框。
- 主操作「开始播放」44px 通栏——整个窗口只有一个高饱和块。
- 底部：状态点 + 登录态 + 两个低频文字动作（扫码登录 / 设置）；两个入口都直接打开同一个设置窗口。

新增行为：点「粘贴」直接读剪贴板；Enter 直接起播；错误信息固定占一行，不挤压布局。

### 设置（712 × 476，卡片铺满窗口，无外壳留白）

- 左栏 200px 导航：账号 / 播放 / 窗口，每项两行（中文 + `ACCOUNT / PLAYBACK / WINDOW` 小标）。选中项只有一条 2px 黄铜竖线和一层微亮底。
- 右栏三个独立页面（`QStackedWidget`），不再是一条长滚动：
  - 账号：登录态面板 + 扫码登录按钮 + 可选 Cookie 文件 + 隐私说明。
  - 播放：倍速 / 音量两条滑杆 + 六项快捷键速查（键帽 + 说明）。
  - 窗口：四档尺寸预设 + 两档开关；预设行实时显示 `480 × 270`。
- 底栏固定：配置说明 + 恢复默认 + 取消 + 保存。
- 修掉旧版一个无效选项：`自定义` 预设本来没有实现，已移除。

### 分P选择（640 × 620）

- 标题区：`课程合辑 · 共 N 个分P` + 合辑名（超长自动省略）。
- 列表行 52px，委托自绘三列：`P3`（Consolas）/ 标题 / 时长（右对齐）。
- 当前项：整行微亮底 + 左侧 2px 黄铜线；悬停只抬一层明度。
- 双击或 Enter 直接播放，Esc 取消。

### 扫码登录（340 × 520）

- 深色窗口里唯一的亮面是 236px 白底二维码，扫得动也压得住。
- 状态文案居中，失败变珊瑚色；「登录态仅保存在本机，不会上传」作为信任说明。
- 保留原有后台线程与轮询逻辑，只换视觉。

## 五、代码落点

| 文件 | 作用 |
|---|---|
| `app/ui/theme.py` | 设计令牌 + 基础 QSS（不再在子控件上 setStyleSheet） |
| `app/ui/widgets.py` | 品牌标 / 窗口按钮 / 开关 / 分段 / 滑杆行 / 设置行（全部自绘或统一样式） |
| `app/ui/launcher.py` | 启动器重写，保留 `play_requested` / `login_requested` / `show_error` 等 API |
| `app/ui/settings_dialog.py` | 双栏设置，保留 `Config` 读写与 `exec()` 阻塞接口 |
| `app/ui/part_picker_dialog.py` | 自绘行委托，保留 `selected_part` / `exec()` |
| `app/ui/qr_login_dialog.py` | 视觉统一，新增 `start_worker=False` 供离屏截图使用 |
| `tools/render_ui.py` | 一次渲染六个界面，支持 `--only` / `--page` / `--logged-in` / `--flat` |

兼容性：`main.py` 只加了一行 `app.setFont(app_font())`；四个窗口对外的信号、方法、返回值没有变，47 个测试全部通过。

## 六、评审过程

| 轮次 | 看到的问题 | 改法 |
|---|---|---|
| v2 | 启动器输入到主按钮之间空 30px；设置页 560 高、下半页大片空；分P 最后一行被底栏切掉 | 错误行压到 18px；设置降到 520 并加「快捷键」区块；分P 行高 52、窗口 620 |
| v3 | `尺寸预设` 的 `480 × 270` 与左侧说明挤在同一基线；设置页标题过粗；说明文字偏暗 | 尺寸并入说明行；页标题降到 500 字重；`FAINT` 提亮到 `#8D8375` |
| v6 | 设置打开时焦点落在空 Cookie 输入框，黄铜边框抢眼 | 打开时焦点交给窗口本身，字段聚焦才亮 |

## 七、验收

- `pytest tests -q` → **47 passed**。
- 离屏截图：`demo_out/v6/*.png`（150% DPI，真实 Windows 平台插件渲染，中文字形正常）。
- 冻结版：`dist/StudyFloat_v6/StudyFloat_v6.exe` 启动验证通过（窗口标题 `StudyFloat`，响应正常，可正常关闭）。
- 包体积与上一版一致：安装 210.0 MB / 7z 63.8 MB（UI 改动不引入新依赖）。

## 八、还没做的

- 明暗主题切换：当前只有暖夜一套；亮色需要再做一套令牌，不是简单反色。
- 启动器「最近播放」列表：`config.recent_urls` 已在存，但界面还没接。
- 播放窗口 OSC 配色：仍是 mpv 默认蓝灰，没有跟黄铜主题统一。
- 动效：只有开关旋钮 150ms；窗口进出、页面切换仍是即显。
