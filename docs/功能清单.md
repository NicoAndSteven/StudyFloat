## 后续开发建议

1. 绿色版已精简掉未使用的 Qt WebEngine/Qml/Quick（810MB → 208MB）；mpv.exe 静态编译约 117MB 是必要成本，若改用动态链接版 mpv + 外部 FFmpeg DLL 可再降体积但会增加依赖复杂度。
2. 实现 P1 系统托盘与完整右键菜单，提升多任务体验。
3. 播放中直链过期自动重载（当前需手动重播）。
4. 为可执行文件和 mpv.exe 签名，减少杀毒误报。
